# Recording script · target 2 minutes 45 seconds

Before recording: configure keys, test live extraction once, verify sandbox buyer login, and use a fresh demo database with an unpaid invoice. Keep the buyer ready in a separate browser profile. Set the app to English, the sample ₹6,000 balance, and availability 16 Nov 2026. Rehearse first. Hide credentials and browser password prompts. Record the actual sandbox payment; do not substitute the mocked tests.

Chat-first entry: start with **Try the laptop repair story**, then use **Review sources & payment** to reach the detailed plan used below. Return with **Back to our conversation** after payment to show the updated chat-side gap. Free-form messages require the live OpenAI key. A lender-review summary is a draft, not a loan sanction.
